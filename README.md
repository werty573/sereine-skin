# Sereine Skin Studio: concept website

A single-page site for **Sereine Skin Studio**, a fictional medical-grade skin clinic in Chaguanas, Trinidad.

Concept build by **Portside Digital**: websites that work. Sereine is not a real business.

**Look:** Cormorant + Jost; warm stone, greige and espresso, with dappled leaf-shadow light and a champagne satin ribbon.

**Scroll animation** (GSAP + ScrollTrigger + Lenis smooth scroll, switched off for people who prefer reduced motion):
- Loader wordmark wipes in, then the hero lines rise
- Hero portrait sits in an arch, then opens to full-bleed as you scroll ("Clear. Calm. Even.")
- Marquee that speeds up with scroll velocity
- Philosophy statement fills in word by word
- Treatments pinned as a horizontal track with in-card parallax and a progress line
- "Journey" cards (Day 1 → Month 2+) stack and settle back as you scroll
- Before/after drag slider that sweeps once on entry (illustrative: real client photos go here)
- Tabbed price menu with a sliding ink pill
- Holiday Edit: satin ribbon draws itself, packages cascade in
- 3D gift card turns on scroll, tilts with the cursor, and counts up to the selected tier
- Booking widget (treatment, next open days Tue to Sat, time, name), with a validated demo success state

Forms don't send anywhere. On a client build, booking would link to the owner's scheduler or WhatsApp.
